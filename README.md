### 👨‍💻 Engineering Profile

I design and build **end-to-end software systems** that bridge **3D Computer Vision / Deep Learning pipelines** with scalable **asynchronous backends** and **cross-platform mobile applications**.

- **3D Vision & AI:** Point cloud registration (ICP), 3D mesh reconstruction, monocular depth estimation (Depth Anything, NeRF, 3D Gaussian Splatting), and semantic segmentation (SAM, YOLO, PointNet).
- **Backend Architecture:** High-concurrency RESTful APIs, asynchronous task queues, database schema design, and ORM optimization using **FastAPI, PostgreSQL, Redis, and Celery**.
- **Mobile & Client Engineering:** Responsive cross-platform applications and interactive 3D model viewports built with **Flutter (Dart)**.
